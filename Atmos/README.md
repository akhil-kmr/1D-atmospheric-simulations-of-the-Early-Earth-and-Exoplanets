# Model

Final simulations. Filenames are indicative of the WACCM6 generated PT profile used. Sub-folders indicate the solar zenith angle used. For each zenith angle, the appropriate
diurnal factor was utilised (0.5 for solar zenith angle of 60, 3/8 (0.375) for 48.2, and 0.354 for 45 degrees). Simulations were uncoupled.
