This repository contains a photochemical grid generated using photochem. The data explores the parameter space of the early Earth's atmosphere evolving over time, varying the thermal structure, atmospheric composition, and solar flux. The filenames are organised into folders with PT profiles generated by WACCM6 for each oxygenation state. Individual simulations are named based on the atmospheric oxygen boundary condition (in %PAL) and the age of the sun in Ga (Sun_X.X Ga). In cases where other parameters were varied (e.g Solar zenith angle, methane boundary condition, surface albedo etc), these are in separate folders (usually in 100% PT profile or 0.1% PT profile)

PI atmosphere config files includes files used to setup and run simulations for a 100% PAL atmosphere on Earth and Proxima Centauri b. Contact authors for additional simulation config files.
