## Overview
This repository hosts the data and configuration files for the study: **"The development of the ozone layer under an evolving Sun"**. 

We explore the evolution of Earth's ozone ($O_3$) layer across geological history. By simulating thousands of atmospheric states, we investigate how the ozone layer responds to:
1.  **Atmospheric Oxygenation:** Varying $O_2$ levels from the Archean to the modern day (0.1 to 150 % of Present Atmospheric Levels).
2.  **Solar Evolution:** The "Faint Young Sun" problem and the changing solar UV spectrum over the last 4.0 Ga.
3.  **Thermal Structure:** Self-consistent Pressure-Temperature ($P-T$) profiles derived from 3D General Circulation Models (WACCM6).
4.  **1D Model Choice** Internal variations between lead to differences in modelling outcome. We benchmark several open source 1D Models against a coupled-chemistry climate 3D general circulation model.
